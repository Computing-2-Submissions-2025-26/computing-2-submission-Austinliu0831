(static) movePiece(gameState, pieceId) → {Ludo.GameState}

Description:

  • Moves the selected piece forward according to the dice value. Pieces that are still at Home can only enter the board when the dice value is 6. Each player first moves around the shared public path from progress 0 to 21, then enters their own final lane from progress 22 to 26. If a piece lands on an opponent's piece on the shared public path, the opponent's piece will be sent back Home.
